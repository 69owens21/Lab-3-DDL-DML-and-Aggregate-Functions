# Lab-3-DDL-DML-and-Aggregate-Functions
his repository contains SQL scripts and exercises for Lab 3. The exercises focus on core database management concepts, including Data Definition Language (DDL) constraints, Data Manipulation Language (DML) transactions, and querying data using aggregate functions and grouping clauses.


Topics Covered

1. DDL, DML, and Transaction Control

User Management: Creating users and granting permissions.

Transaction Control (TCL): Using ROLLBACK and COMMIT to manage data insertion states.

Table Constraints: Enforcing data integrity by adding and testing PRIMARY KEY, NOT NULL, and Foreign Key constraints.

Data Behavior: Observing database responses when inserting NULL or duplicate values.

2. Aggregate Functions & Data Querying

Aggregations: Utilizing COUNT, MIN, SUM, and AVG to perform calculations on datasets.

Data Grouping & Sorting: Applying GROUP BY, ORDER BY (Ascending and Descending), and HAVING clauses to organize and filter query results.

Views: Creating a database view to isolate specific columns (e.g., Age) from the main table.
